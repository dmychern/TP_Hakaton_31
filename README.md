# Система автоматической обработки корпоративной почты

Проект разработан в рамках хакатона по курсу "Технологии программирования".

## Описание
Данная система предназначена для автоматизации сортировки входящих писем отдела IT-поддержки. Она классифицирует письма по категориям (Техподдержка, Клиентская поддержка, Спам, Новости и др.) на основе ключевых слов и регулярных выражений, после чего перемещает их в соответствующие папки.

## Основные возможности
- **Классификация на основе правил:** Гибкая настройка категорий через JSON-конфигурацию.
- **Поддержка приоритетов:** Категории с более высоким приоритетом имеют преимущество при совпадении ключевых слов.
- **Обработка ошибок:** Система корректно обрабатывает пустые письма, неизвестные форматы файлов и проблемы с кодировкой.
- **Логирование:** Подробный журнал работы сохраняется в `data/logs/app.log`.
- **Отчетность:** По завершении обработки формируется отчет `reports/reports.json` со статистикой и деталями по каждому письму.

## Архитектура
- `RuleBasedClassifier`: Логика классификации текстов.
- `MailProcessor`: Управление процессом чтения, перемещения файлов и генерации отчетов.
- `EmailMessage`, `CategoryRule`: Модели данных.

## Установка и запуск
1. Убедитесь, что у вас установлен Python 3.12+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Поместите входящие письма в папку `project/inbox/`.
4. Запустите систему с помощью bash-скрипта из директории `project/`:
   ```bash
   cd project
   bash run.sh
   ```

## Тестирование
Для запуска тестов используйте команду:
```bash
cd project
python3 -m pytest tests/
```
